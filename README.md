flowchart TB
    A((아이디/비밀번호 찾기 화면)) --> B{선택}
    B -->|아이디 찾기| C(아이디 찾기 입력)
    B -->|비밀번호 찾기| D(비밀번호 찾기 입력)
    
    C --> E[DB 조회: (이름, 이메일/휴대폰)]
    E --> F{회원 존재?}
    F -- Yes --> G[부분 Block 처리된<br>아이디 노출<br>(예: abcd****)]
    F -- No --> H[“해당 정보의<br>회원이 없습니다.”<br>안내 후 종료]

    D --> I[아이디, 이름, 이메일/휴대폰<br>+ 인증방식 선택<br>(이메일 or SMS)]
    I --> J[DB 조회: 해당 회원 존재?]
    J -- Yes --> K[인증코드 전송<br>(이메일 or SMS)]
    J -- No --> L[“해당 정보의<br>회원이 없습니다.”<br>안내 후 종료]
    
    K --> M(인증번호 입력)
    M --> N{인증번호 유효?}
    N -- Yes --> O[새 비밀번호<br>재설정 화면]
    N -- No --> P[“인증번호가<br>유효하지 않습니다.”<br>재시도 안내]
    O --> Q[비밀번호 재설정 완료<br>로그인 페이지로 이동]
